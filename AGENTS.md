# Pocket Android

Pocket — самостоятельная производная Shelter. Исходная точка:
`0afac87b2dc34e58652d6bb3cebb61b1baaf1b98`, remote `upstream`.
Java namespace `net.typeblog.shelter` сохраняется для минимального изменения кода;
идентичность APK — `io.github.nekontritce11123.pocketandroid`, название Pocket,
минимум Android 10 (API 29). Сохраняй авторство и лицензии исходных компонентов.

Пользователь разрешил продолжить все этапы согласованного плана 0–8: профиль,
Always-on/lockdown, Hysteria 2 и VLESS + REALITY, импорт, приложения, ярлыки и
проверенный APK. Политика и состояние связи показываются раздельно; до реальной
проверки нельзя обещать защищённое подключение. Пользователь также разрешил взять
его казахстанское подключение из прошлой разработки и загрузить на тестовый POCO.
Секреты передаются локально в приватные данные тестовой установки, не в Git/APK,
не в отчёты и не в Beads. Помощники не читают реальные ключи и пароли.

Сохраняй provisioning, установку base/split APK, запуск рабочих копий и ярлыки.
Автозаморозка, файловый мост и NFC-заглушка исключены из продукта. Не переименовывай
внутренние Java-классы ради брендинга. Не меняй проект Pocket Windows.

Задачи, существенные решения, проверки и блокеры хранятся только в проектном
Beads (`bd`); отдельный markdown-трекер или файл памяти не создавай. Перед
продолжением прочитай `bd prime` и задачи текущего поручения. После изменений
базы выполни `bd backup sync`. Beads последовательно изменяет основной агент.

`.tools/`, `.local/` и `.artifacts/` — локальные игнорируемые каталоги инструментов,
подписи и доказательств. Не коммить ключи, пароли, APK, SDK, журналы или данные
телефона. Настройки SDK и подписи локальные; системные JAVA_HOME/PATH не меняй.

Сборка не подтверждает запуск на телефоне. Проверки POCO и независимое наблюдение
сети фиксируй отдельно; недоступная обязательная проверка остаётся незавершённой.
Пользователь уже создал собственный профиль Pocket (на POCO profile owner —
Pocket, user 11). Сохраняй этот профиль и его данные при обновлениях. Не удаляй
и не пересоздавай его для исправления ошибок; чужие пространства не меняй.
Не публикуй APK и не отправляй изменения в upstream без отдельного поручения.
